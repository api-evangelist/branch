# Branch Insurance

Branch is a home and auto insurance platform built on an API-first model. Partners can embed Branch's insurance products directly into their own workflows using the Quote to Bind GraphQL API, enabling customers to get quotes and purchase home, auto, renters, and umbrella insurance in seconds.

## APIs

- **Quote to Bind API** - GraphQL API for full insurance lifecycle management: quoting, binding, payment, and policy document retrieval
